# PRD 05 - Dashboard Admin

## Obiettivo

Permettere ad admin di monitorare utenti, zone, SOS, segnalazioni, impostazioni e storico azioni.

## Sezioni

- Overview;
- utenti;
- zone;
- SOS attivi;
- storico SOS;
- feedback zone;
- segnalazioni;
- notification logs;
- impostazioni app;
- AI settings;
- premium limits.

## Permessi

Solo ADMIN accede a `/admin`.

## Admin vede

- autore segnalazioni;
- storico azioni;
- stato notifiche;
- zone più pericolose;
- SOS attivi in tempo reale.

## Admin può

- modificare zona;
- cambiare stato servizio zona;
- correggere safety score;
- approvare/rifiutare segnalazioni;
- modificare limiti FREE/PREMIUM;
- abilitare/disabilitare AI;
- impostare provider AI/SMS/email.

## Criteri accettazione

- admin login;
- dashboard accessibile;
- dati principali visibili;
- utente normale bloccato.
