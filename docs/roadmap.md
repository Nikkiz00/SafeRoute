# Roadmap generale SafeRoute

## Metodo

Sviluppare a giornate, non a mega task.
Ogni giornata deve essere completabile da Claude Code senza saturare il contesto.

## Giornate

1. Foundation: repo, FE/BE, Prisma, env, healthcheck.
2. Auth + onboarding + emergency contacts.
3. Mappa + zone + import dati.
4. Routing + feedback + safety score.
5. SOS + email/SMS + tracking live.
6. Admin dashboard.
7. Polish, testing, deploy.

## Cosa rimandare

- Pagamenti reali;
- AI avanzata;
- app mobile nativa;
- estero;
- notifiche push reali;
- integrazione 112 automatica.
