## Flusso utente verificato (logica)

1. **Registrazione**: POST /api/auth/register → token salvati → redirect /onboarding
2. **Login**: POST /api/auth/login → token salvati → redirect /map o /onboarding
3. **Refresh pagina**: auth.init() → GET /api/auth/me → refresh se scaduto → user ripristinato
4. **Logout**: POST /api/auth/logout → token revocati server → localStorage pulito → /login
5. **Onboarding**: 6 step → PATCH /api/profile/onboarding → onboardingCompleted=true → /map
6. **Contatti**: GET al mount → POST/PATCH/DELETE con limiti FREE(2)/PREMIUM(5) → errori mostrati
