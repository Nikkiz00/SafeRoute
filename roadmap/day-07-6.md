## Implementato

### Backend
- [x] Schema Prisma: `users.emailVerified`, `users.emailVerifiedAt`, `EmailVerificationToken`, `route_sessions.destinationName`
- [x] `POST /api/auth/verify-email` — verifica token via GET query param
